# ISO de Nanuk

Perfil de [archiso](https://wiki.archlinux.org/title/Archiso) con el que se
construye la ISO de instalación de Nanuk.

Para **instalar** Nanuk no necesitas nada de esta carpeta: descarga la ISO de
[Releases](https://github.com/nestervear/nanuk/releases/latest) y sigue
[docs/instalar.md](../docs/instalar.md).
