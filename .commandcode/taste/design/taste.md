# Design preferences

- Prefers a minimalist, sober, elegant dark theme: black and white with an ice-blue accent, square shapes (no rounded corners, no gaps), inspired by Vantablack and Celestia Dots. Confidence: 0.9
- Dislikes transparency effects. Confidence: 0.8
- Wants polar bear branding/motifs (boot/login logo, update icon, etc.). Confidence: 0.8
- Wants a consistent, unified icon theme across the whole system so the theme looks like one. Confidence: 0.75
- Prefers widgets to show a qualitative summary rather than raw numbers (e.g., weather shows the overall condition — sunny/cloudy/rain — instead of the temperature). Confidence: 0.8
- Prefers icon-only widgets in the status bar (e.g., weather shows just the icon, with temperature/condition moved into the tooltip). Confidence: 0.7
- Wants selection/highlight states rendered in the ice-blue accent so they are clearly visible on the black background (not a near-invisible gray). Confidence: 0.7
- Insists that no text, label, or variable ever be left the same color as its background (unreadable/black-on-black); legibility takes priority over aesthetics across every part of the theme. Confidence: 0.8
- Dislikes visually fragmented elements where multiple backgrounds stack (e.g., a black box behind a selected icon that clashes with the surrounding color); prefers a single clean, uniform treatment (e.g., just an ice outline). Confidence: 0.7
- Wants the shell prompt to carry a status indicator of the last command: an ice-blue circle on success, a cross on error — shown only after a command has actually run; the first prompt of a fresh shell should stay bare (just `~ ❯`). Confidence: 0.8
